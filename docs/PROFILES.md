# MNCM Labs Installation Profiles

## Complete

Package groups:

    core
    developer
    shell
    editor
    terminal
    desktop

Dotfile components:

    zsh
    ghostty
    nvim
    hypr
    waybar
    vscode

Use case:

A complete MNCM Labs Arch Linux development workstation.

## Developer

Package groups:

    core
    developer
    shell
    editor
    terminal

Dotfile components:

    zsh
    ghostty
    nvim
    vscode

Use case:

Development-focused system without installing the complete Hyprland desktop package group.

## Minimal

Package groups:

    core
    shell
    editor

Dotfile components:

    zsh
    nvim

Use case:

Lightweight command-line development environment.

## Custom

Package groups and dotfile components are selected interactively.

Use case:

Users who want to build their own MNCM Labs configuration.
